- **스토리**
  - **최후의 투표: 무력으로 결정되는 지구 대통령**
  - 민주주의가 몰락하고 투표 대신 무력으로 지도자를 선출하는 황당한 미래 사회가 도래했습니다.
  - 현실로 소환된 두 정치적 거물, **[트럼프]**와 **[푸틴]**.
  - 단 한 명의 '지구 대통령' 자리를 차지하기 위해 벌어지는 기괴하고도 치열한 난투극을 유쾌하게 풀어낸 정치 풍자 시뮬레이션입니다.

- **게임 목표**
  - **현실 공간에 소환된 캐릭터들의 다채로운 상호작용을 경험하세요.**
  - 승패를 가르는 경쟁보다는, 현실 공간 위에서 펼쳐지는 캐릭터들의 다채로운 상호작용을 경험하는 데 초점을 맞춘 **[체험형 AR 턴제 시뮬레이션]**입니다.
  - 턴마다 달라지는 선택에 맞춰 실시간으로 휙휙 바뀌는 3D 모델들의 코믹한 움직임과 연출을 감상하며, 현실과 가상이 결합된 독특한 시각적 재미를 느껴보세요.

# 🎮 조작 및 플레이 방식

- **AR 캐릭터 소환 :**
  - 카메라로 [푸틴]과 [트럼프]의 이미지 타깃(카드)을 동시에 인식하여 3D 캐릭터 모델을 소환시키며 게임을 시작합니다.

- **선공 주사위 시스템 :**
  - 게임 진입 시 주사위를 굴려 두 캐릭터 중 먼저 공격할 우선순위를 결정합니다.

- **턴제 스킬 선택 :**
  - 화면 하단에 나타나는 스킬 버튼을 터치하여 공격합니다. 상대방에게 무작위 데미지를 입히며 턴을 주고받습니다.
